# Render Deployment Guide

This project is deployed as:
- `server` -> Render Web Service (Node.js + Prisma)
- `client` -> Render Static Site (Vite)
- Render PostgreSQL database

## 1) Pre-deploy checks

1. Copy env templates:
   - `server/.env.example`
   - `client/.env.example`
2. Confirm Prisma datasource is PostgreSQL in `server/prisma/schema.prisma`.
3. Ensure local build works:
   - `cd server && npm install && npm run db:generate`
   - `cd client && npm install && npm run build`

## 2) Deploy with Blueprint

1. Push repository to GitHub.
2. In Render, create new Blueprint and select this repo.
3. Render will read `render.yaml` and create:
   - PostgreSQL: `entegrasyon-db`
   - Backend service: `entegrasyon-server`
   - Frontend service: `entegrasyon-client`

## 3) Required environment values

After creation, set the following manual values in Render:

- Backend (`entegrasyon-server`)
  - `CORS_ORIGIN=https://<your-frontend-domain>`
- Frontend (`entegrasyon-client`)
  - `VITE_API_BASE_URL=https://<your-backend-domain>/api`

`JWT_SECRET` is auto-generated by Blueprint.

## 4) Runtime behavior

- Backend build command:
  - `npm install && npx prisma generate`
- Backend start command:
  - `npx prisma migrate deploy && npm start`
- Frontend build command:
  - `npm install && npm run build`
- Frontend publish path:
  - `dist`

## 5) Smoke test checklist

1. Health:
   - `GET https://<backend-domain>/api/health` returns 200.
2. Auth:
   - Register and login from frontend, verify token-protected calls.
3. XML flow:
   - Add one XML source and run sync.
4. Marketplace flow:
   - Test Trendyol connection, send at least one product.
5. Orders:
   - Trigger order sync and verify records.
6. Stability:
   - Check Render logs for CORS/401/timeout/rate-limit issues.

## 6) Rollback

If deployment fails:
1. Revert latest commit.
2. Redeploy previous healthy commit from Render dashboard.
3. Re-check `DATABASE_URL`, `CORS_ORIGIN`, and `VITE_API_BASE_URL`.
